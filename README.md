# video-editor

A workflow for making short videos with Claude: script → voiceover → animation or edit → review.
See `CLAUDE.md` for how the repo is organised and which skills do what.

First project: `projects/trip-social-01/`, a short social clip for the Trip app.

Setup on a new machine: `bash scripts/setup.sh` (links `profiles/` into `~`). In Claude Code the
skills in `.claude/skills/` load automatically for this repo.
