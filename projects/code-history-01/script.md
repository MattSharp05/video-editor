## Claim check (fresh agent, 2026-11-13)
- ENIAC set-up took days per problem: CHM https://www.computerhistory.org/revolution/birth-of-the-computer/4/78

- Front-panel switches were mainly for short loaders: hence "Some machines".
- ADD is a real IBM 704/709 mnemonic: https://www.manualslib.com/manual/1342813/Ibm-709.html?page=16
- Batch turnaround minutes to hours to overnight: Cornell https://www.cac.cornell.edu/about/pubs/History_Computing_Cornell_Rudan.pdf
- First interactive terminals printed on paper: CHM https://computerhistory.org/blog/the-apl-programming-language-source-code/
- Syntax colour 1983, code completion 1996 (VB5 CCE).
