# Music

## Floating Cities (Kevin MacLeod) — the 3D explainer series' song
Matthew's pick (2026-11-17, sound picker), used on every video in the series (2026-11-19: "they must all use this
voice and song"). Licence CC BY 4.0: caption credit "Music: "Floating Cities" by Kevin MacLeod (incompetech.com),
CC BY 4.0". The file stays out of git; `./fetch.sh` downloads it to `library/music/files/Floating_Cities.mp3`.

Mix it as `projects/turbulence-seat-01/film/sound/mix.py` does: sidechain-ducked under the voice, measured ~10-12 dB
under the voice during speech (there: music at +6 dB in that script measured 11.1 dB), whole mix loudnorm -14 LUFS.
Start the song at 0 and fade the last ~1.5 s; trim, don't loop (it is 3:30+ long).
