# Agent skills for generating / modelling 3D geometry (beyond the terrain/water/lighting set)

Scope: SKILL.md repos and MCP servers that help an agent *model* geometry (procedural meshes, Blender automation, organic/character forms, instanced towns, trails, dissolve) for a Remotion + three.js r169 + R3F 8 explainer rendered headless (SwiftShader WebGL2, CPU only). Research done 2026-11-06 via GitHub code/repo search (`gh api search/...`) and the raw SKILL.md files themselves. Star counts and push dates are from the GitHub search API on that date. Note: the GitHub repos API was blocked in this session, so licences come from the search API's `license.spdx_id` field or the SKILL.md frontmatter.

## Which SKILL.md repos cover procedural modelling / mesh generation / Blender automation?

### Takeaway
Eight distinct, relevant skill sets exist. The strongest for *modelling* are (a) **EL4CTEO/blender-skills** (28 tested Blender 5.2 skills that run headless, MIT), (b) **InstruktAI/TeleClaude `threejs-procedural-assets`** (the most directly usable three.js recipe for organic bodies; GPL-3.0), (c) **BradyAJohnston/nodebpy** (Geometry Nodes as Python, headless via the pip `bpy` wheel; GPL-3.0) and (d) **ahujasid/blender-mcp** (now `ahujasid/mcp-for-blender`, 33k stars, MIT; needs a live Blender with its add-on). The three.js "compiler-style" packs (linegel, scottstts, jorgeasaurus) target r185 WebGPU/TSL and are more about architecture than recipes. img2obj is a heavy reference-image-to-procedural-three.js workflow.

Covers instancing, repeat/simulation/for-each zones, and SDF grids (`MeshToSDFGrid`, `SDFGridBoolean`, `SDFGridFillet`, `SDFGridOffset`, `GridToMesh`) for "smooth booleans, remeshing, fillets". Rules: always expose a `Seed`; "Realize Instances only when you must"; named attributes (prefix `_`) export through glTF. — [blender-geometry-nodes SKILL.md](https://github.com/EL4CTEO/blender-skills/blob/main/skills/blender-geometry-nodes/SKILL.md)
- The verified GN recipes file covers scatter on a surface, pipe/cable along a curve, a repeat zone (iterative subdivide), and storing a mask attribute for shaders/export. — [references/recipes.md](https://github.com/EL4CTEO/blender-skills/blob/main/skills/blender-geometry-nodes/references/recipes.md)

**3. BradyAJohnston/nodebpy (skill `nodebpy`)**
- 132 stars, GPL-3.0, last push 2026-10-29. "Build node trees in Blender more elegantly with code." — [GitHub](https://github.com/BradyAJohnston/nodebpy)
- The skill builds Geometry Nodes, shader and compositor trees as Python. Every node is a typed class, `>>` links nodes, and Python operators build Math/Compare nodes. Runs headless: `uv add nodebpy "bpy==5.2.*" matplotlib` then `BLENDER_USER_EXTENSIONS=/nonexistent uv run python build_tree.py`. Its errors are designed to be agent-fixable ("a mistyped enum lists the closest options"). It warns that "`>>` picks sockets by type, and an unlinked input silently uses its default", so the result must be verified by counting nodes and links and evaluating the geometry. References cover repeat/simulation/for-each/closure zones. — [nodebpy SKILL.md](https://github.com/BradyAJohnston/nodebpy/blob/main/skills/nodebpy/SKILL.md)
- PyPI `bpy` is at 5.2.3 with a `cp313 manylinux_2_28_x86_64` wheel (matches the container's Python 3.13) — [PyPI bpy JSON](https://pypi.org/pypi/bpy/json)

**4. InstruktAI/TeleClaude: `threejs-procedural-assets`**
- Repo: 1 star, GPL-3.0, pushed 2026-11-06 (it is an agent framework; the skill is one file set inside it) — [GitHub](https://github.com/InstruktAI/TeleClaude)
- It bans "glue together spheres, cylinders and boxes". It says realism comes from (1) a silhouette made of continuous curved surfaces, (2) a frequency hierarchy (silhouette → mid features → fine noise), and (3) the rendering stack (tone mapping, env map, PBR, soft shadows). Asset table: organic body = "Lofted spline surface: spine curve + swept cross-sections"; scatter/cities = "InstancedMesh with per-instance variation"; vegetation = recursive branching skeleton. Guidance: "100+ segments along the main axis, 48–64 radial"; "a 100k-triangle asset renders fine"; "Animate by deformation"; it supports R3F/TS. — [SKILL.md](https://github.com/InstruktAI/TeleClaude/blob/main/agents/global/skills/threejs-procedural-assets/SKILL.md)
- Includes a concrete `buildLoftedBody(spine, widthProfile, heightProfile, segs=160, radial=64)` using `CatmullRomCurve3.computeFrenetFrames` with an elliptical section in the normal/binormal plane. Width and height are "separate 1D functions of t"; caps come from converging profiles to ~0 "never plug holes with spheres"; limbs are "separate lofts ... root sunk slightly into the body"; skin detail is "2–3 octaves of simplex noise at ~0.5–2% of body radius" along normals. Scatter: one InstancedMesh per type, `setColorAt` hue variation, noise-clustered density with rejection, "2–3 geometry variants ... beats one variant at 3× the count". — [references/geometry.md](https://github.com/InstruktAI/TeleClaude/blob/main/agents/global/skills/threejs-procedural-assets/references/geometry.md)

### Inferences
- Best fit for the stack: keep the film in three.js and borrow TeleClaude's loft/scatter recipes plus the Summer dissolve logic (ported to `onBeforeCompile` or a `ShaderMaterial` GLSL ES 3.0). Use Blender (EL4CTEO + nodebpy via pip `bpy`) only as an offline asset baker that writes GLB, for shapes three.js recipes do badly (the brain, the sleeping figure).
- linegel/scottstts/jorgeasaurus skills are written for r185 WebGPU/TSL. Their TSL code will not run on r169 + WebGL2/SwiftShader. Their topology and representation guidance still carries over.
- blender-mcp's live loop needs an interactive Blender with the add-on running. In a headless container EL4CTEO's background runner or nodebpy's `uv run python` path is the practical route.

### Gaps
- Could not read repo trees or confirm licence files directly (repos API blocked); licences come from search metadata or frontmatter.
- Did not verify whether blender-mcp's add-on socket server works in `blender -b` mode (it depends on Blender timers/event loop). Treat as unsupported until tested.
- Did not test EEVEE in background mode without a GPU. Cycles CPU is the safe assumption for headless renders. Previews in EL4CTEO's `review_shots.py` may use Workbench/EEVEE (unverified).

### Inferences (techniques to borrow per weak area; my synthesis, not from any one skill)
1. **Brain with gyri/sulci.** Start from two ellipsoid hemispheres (lofted or a subdivided sphere, non-uniform scale, flattened medial face, a temporal-lobe bulge) with a gap for the longitudinal fissure. Displace along normals with *ridged* noise (`1 - abs(noise)`, the ridge trick TeleClaude gives for terrain), domain-warped, so ridges read as folded gyri and the creases as sulci. Displacement ~3–6% of radius, far above the 0.5–2% "skin" band. Darken the creases via a cavity/AO term from the same noise value. In Blender, the equivalent is EL4CTEO's `detail` noise plus voxel remesh plus GN noise displacement, baked to GLB. Needs dense tessellation (100k+ tris is fine per TeleClaude).
2. **Sleeping man's head and body.** Use TeleClaude's lofted-body pattern: a spine curve lying horizontal, separate width/height profiles with anatomical landmarks (neck pinch, shoulder width, rib cage, waist, hips), and limbs as separate sunk lofts. Breathing = deforming the chest profile over time (its "animate by deformation" rule). A duvet hides most anatomy: a GN/cloth or noise-displaced plane draped over the loft. For a more believable head, a Blender headless pass (metaball/Skin blockout → voxel remesh → smooth/inflate; proportions from EL4CTEO's human-proportions reference) exported to GLB.
3. **Stylised town and tiny glowing town.** Grammar-built houses (footprint → extrude → roof inset) merged per material, plus InstancedMesh for repeated modules, with `setColorAt` variation and noise-clustered placement. For the "tiny glowing town", reuse the same instances at small scale with emissive window material and selective bloom.
4. **Light ribbons / trails and crumble-from-edges.** Ribbons are TubeGeometry or camera-facing strips along CatmullRom splines, with a `uProgress` uniform clipping along the curve parameter. Particles are pure functions of `(seed, frame)`, which suits Remotion's frame-addressed rendering because every frame is reproducible. For "crumble from the edges", add a distance-from-boundary or radial term to Summer's noise threshold (`n + k * edgeDistance < threshold`), so the dissolve front starts at the silhouette or rim and moves inward. Optionally spawn instanced fragment/ash particles where the rim passes. Summer's recipe is plain uniform-noise only; the edge-biased variant is my extension.
5. **Neurons.** Soma = small noise-displaced sphere. Dendrites/axon = recursive branching skeleton (TeleClaude's vegetation pattern) swept as tapered tubes with parallel-transport frames (linegel). Synapse pulses = emissive points travelling along the same splines (analytic in time). Many neurons = InstancedMesh of 2–3 variants.

### Gaps
- No skill found that models a cortex/brain, a human body (beyond Blender rigging/sculpt workflows) or neurons procedurally. The mappings above are synthesis.
- Performance of 100k+-triangle displaced meshes and bloom under SwiftShader was not measured in any source; budget a test render.
- No skill gave an edge-biased ("from the edges") dissolve; only uniform noise-threshold dissolve.

### Inferences
- GPL-3.0 (nodebpy, TeleClaude): copying the skill text or scripts into the vendored `.claude/skills/` brings GPL obligations for those files. Re-implementing the techniques (lofting, noise displacement) in our own code avoids that. This is not legal advice; note it in `UPSTREAM.md` if vendored.
- The dissolve and trail shaders need only standard GLSL ES 3.0 (noise, `discard`, smoothstep), so they should run under SwiftShader WebGL2. Cost scales with fragment count, so keep FBM octaves low (Summer uses 4).
- Blender in this container: the pip `bpy` 5.2.3 wheel matches Python 3.13, so `uv` can install it without apt. EL4CTEO's scripts call a `blender` executable, so they may need a full Blender 5.2 tarball rather than the wheel (unverified).
